# Task Scheduler (Student Productivity Tool)

A React + Tailwind web app with public pages (Home/About/Contact) and Google Login via Firebase.
After logging in, users access a private Dashboard for task scheduling (in progress).

🔗 Live: https://my-project-a4613.web.app

## Features
- Responsive UI (Tailwind CSS)
- Public pages: Home / About / Contact
- Google Sign-In (Firebase Authentication)
- Protected Dashboard route (logged-in users only)
- Logout

## Tech Stack
React (Vite), Tailwind CSS, React Router, Firebase Auth, Firebase Hosting

## Run Locally
\`\`\`
npm install
npm run dev
\`\`\`

## Status
Dashboard task-scheduling features are still in progress.

## What I learned
Firebase Authentication integration, protected routing in React, and structuring a
multi-page app with Vite.
